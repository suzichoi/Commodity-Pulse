🚀 GitHub Pages 자동 업데이트 구축 안내

1. 깃허브 리포지토리 생성 및 업로드

현재 폴더의 소스코드를 본인의 GitHub 새 저장소(Public)에 푸시합니다.

git init
git add .
git commit -m "feat: initial commit"
git remote add origin https://github.com/사용자ID/원자재-대시보드.git
git push -u origin main

2. GitHub Actions 쓰기 권한 설정

매일 파이썬 스크립트가 실행되어 데이터(commodities.json)를 커밋할 수 있도록 권한을 엽니다.

리포지토리 Settings > Actions > General > Workflow permissions에서 "Read and write permissions" 선택 후 저장!

3. GitHub Pages 활성화

Settings > Pages > Build and deployment 메뉴에서 Build Source를 "GitHub Actions"로 설정합니다.

4. 매일 자동 업데이트 확인

매일 아침 9시(00:00 UTC) 및 오후 5시(08:00 UTC)에 .github/workflows/update_data.yml이 자동으로 코코아, 커피, GDT 우유 시세를 가져와 대시보드를 갱신합니다. Actions 탭에서 "Run workflow"를 눌러 수동 테스트도 가능합니다.
